    DLT698 / C++ & PYTHON

    #把协议细节交给库，把精力留给业务。

    这是 dlt698 的 C++ 与 Python 使用指南及接口文档。两种语言共用同一协议内核，
    面向集中器、采集终端和电力网关等 DL/T 698.45—2017 协议对接场景。

    版本 0.1.0 / C++17 / CMake 3.20+ / 持续更新中

    #从哪里开始

    使用 C++ 看使用指南(C++)；使用 Python 看安装与第一个程序。Python 指南提供简短代码示例，协议概念和点位说明共用已有 C++ 文档。

    1. 先把库装上。 读安装与构建，确认导出目标和编译选项。
    2. 跑通第一个程序。 第一个程序用内存通道完成一次 CONNECT → GET → RELEASE，不需要网络和设备。
    3. 按需深入。 只需要编解码就直接看核心类型；要做完整通信再看会话与服务和传输层。

    #关于本文档

    文档围绕公开接口和实际用法编写。

    C++ 行为以公开头文件为准，Python 签名以公开模块和类型声明为准。Python 按阶段开放能力，共享 C++ 内核和版本；指南重点补充调用顺序、结果处理及生命周期约定。

    当前版本尚未覆盖完整协议。已实现范围、限制和待办集中在协议覆盖范围，跨设备联调前请先确认对应条目。发现文档与实现不一致，欢迎通过页面底部的编辑链接提交修正。

    接口会随 0.x 阶段调整。涉及行为的改动都会在源码和本文档中同步说明。
