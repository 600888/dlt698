## 从哪里开始

1. **先把库装上。** 读[安装与构建](./getting-started/installation.md)，确认导出目标和编译选项。
2. **跑通第一个程序。** [第一个程序](./getting-started/quick-start.md)用内存通道完成一次 CONNECT → GET → RELEASE，不需要网络和设备。
3. **按需深入。** 只需要编解码就直接看[核心类型](./core/result.md)；要做完整通信再看[会话与服务](./session/session.md)和[传输层](./transport/tcp.md)。
